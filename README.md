# Checklist de apertura del restaurante

App sencilla (un solo sitio estático, sin instalación) para abrir un restaurante de ahumados y pasta de 200–300 personas sin que quede nada por fuera.

Tiene tres listas:

- **Antes de abrir** — permisos, local, equipo, ahumados, pasta, menú, salón, bar, personal, proveedores, caja, higiene, mercadeo y ensayos.
- **Apertura del turno** — recorrido de verificación antes de abrir puertas ("esto funciona, esto también…"). Se reinicia cada turno.
- **Cierre** — para dejar todo listo y seguro para el día siguiente.

En cada punto se puede marcar **listo** o **⚠ Falla** con una nota (qué pasa y quién lo resuelve). Las fallas se juntan arriba para verlas de un vistazo. También se pueden agregar puntos propios en cada sección.

## Cómo usarla

Abrir `index.html` en el navegador. Lo marcado se guarda en ese dispositivo (no se sincroniza entre teléfonos); con Exportar / Importar se puede pasar de uno a otro.

## Cómo cambiar el contenido

Todas las listas están en `data.js`, en texto plano.
